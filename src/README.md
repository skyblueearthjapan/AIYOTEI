# AIカレンダー GASソースコード

## ファイル構成

```
src/
├── Config.gs        # 設定値・ヘルパー関数
├── Main.gs          # メインエントリーポイント・カスタムメニュー
├── OpenAI.gs        # OpenAI API呼び出し共通関数
├── Calendar.gs      # カレンダー予定のDB操作
├── Memo.gs          # メモのDB操作
├── Sidebar.gs       # サイドバー関連の関数
├── Log.gs           # ログ機能
├── CopySidebar.html # メモコピー用サイドバーUI
└── LogSidebar.html  # ログ表示用サイドバーUI
```

## セットアップ手順

### 1. スプレッドシートの準備

テンプレートスプレッドシートをコピーして使用してください。
以下のシートが必要です：

- `UI_Calendar` - カレンダー表示用
- `UI_Memo` - メモ表示用
- `DB_Events` - 予定データベース
- `DB_Memos` - メモデータベース
- `DB_Rokuyo` - 六曜マスタ（任意）
- `DB_Log` - 操作ログ
- `Settings` - 設定

### 2. Apps Script プロジェクトの作成

1. スプレッドシートを開く
2. `拡張機能` > `Apps Script` を選択
3. 各 `.gs` ファイルの内容をコピー
4. 各 `.html` ファイルを追加（ファイル > + > HTML）

### 3. スクリプトプロパティの設定

Apps Scriptエディタで：

1. `プロジェクトの設定` (歯車アイコン) を開く
2. `スクリプトプロパティ` セクションで以下を追加：

| プロパティ名 | 値 |
|-------------|-----|
| `OPENAI_API_KEY` | あなたのOpenAI APIキー |
| `OPENAI_MODEL_CALENDAR` | `gpt-4o-mini`（推奨） |
| `OPENAI_MODEL_MEMO` | `gpt-4o-mini`（推奨） |

### 4. 初回実行と権限承認

1. スプレッドシートを再読み込み
2. `AIカレンダー` メニューが表示される
3. いずれかのメニュー項目を実行
4. 権限承認ダイアログが表示されたら承認

## 使い方

### 予定の登録

1. `AIカレンダー` > `予定：テキストから登録` を選択
2. 自然な言葉で予定を入力
   - 例：「来週の火曜15時に歯医者 保険証を持っていく」
3. AIが解析した内容を確認して登録

### メモの追記

1. `AIカレンダー` > `メモ：テキストから追記` を選択
2. メモしたい内容を入力
3. AIが整形した内容を確認して追記

### メモのコピー

1. `AIカレンダー` > `メモをコピー（サイドバー）` を選択
2. サイドバーで「コピー」ボタンをクリック

### 日付の移動

- `メモ：前日へ` / `メモ：翌日へ` でUI_Memoの日付を移動
- `メモ：今日に戻す` で今日に戻る

## カスタマイズ

### AIモデルの変更

スクリプトプロパティで `OPENAI_MODEL_CALENDAR` / `OPENAI_MODEL_MEMO` を変更

### UI_Memoのセル位置

`Main.gs` の `refreshMemoUI()` 関数でメモ表示セルの位置を調整可能

## トラブルシューティング

### 「OPENAI_API_KEY がスクリプトプロパティに設定されていません」

→ スクリプトプロパティに `OPENAI_API_KEY` を設定してください

### メニューが表示されない

→ スプレッドシートを再読み込みしてください

### 権限エラー

→ Apps Scriptの権限を再承認してください
